# DBFLOW

Сайт для обработки таблиц без регистрации и облачного хранилища.

## Разделы

- запуск без регистрации и аккаунта;
- 20 самостоятельных страниц с адресами вида `/#/geo`, а не всплывающие окна;
- выбор файлов и drag&drop в каждом разделе; перетаскивание на рабочий стол или карточку инструмента;
- раздельные списки исходников и справочников, удаление файла до запуска;
- прогресс загрузки, очередь и результаты в истории задач;
- исходники и результаты обрабатываются во временной рабочей папке;
- скачать результат до окончания сессии;
- CSV/XLSX/XLSM/XLS/XLSB/Parquet/TXT/HTML → CSV, XLSX для табличных результатов;
- нормализация телефонов, ФИО и дат;
- очистка текстовых полей;
- удаление первой `7` в колонке телефона;
- дедупликация;
- фильтрация и сортировка по колонке;
- merge нескольких таблиц;
- split большой таблицы на CSV-части внутри ZIP;
- анализ структуры файла;
- база номеров в TXT, GEO, регионы по диапазонам, MAX-сверка;
- ФССП, количество строк в имени, делёжка по кругу, выборка куска с остатком;
- разбиение по номеру исходной таблицы и общий numbers.txt;
- приведение адресов к единому виду с отметкой неоднозначных записей;
- фиолетовый интерфейс, клавиатурная навигация, адаптивная верстка и поддержка уменьшенного движения;
- Polars для быстрой табличной обработки;
- автоматическое удаление исходников и результатов после TTL (по умолчанию 1 час после завершения); очистка восстанавливается после перезапуска.

GEO распознаёт номера с пробелами, скобками, дефисами и другими разделителями, разворачивает их в отдельные строки и сохраняет поля записи.

В «Фильтр + MAX» есть «Убрать 7», «Отфильтровать совпадения» (оставить совпавшие номера), «Скачать несовпадения». Справочник: TXT `номер;MAX` или таблица с номерами. Сравнение не зависит от префикса 7/8. Это сверка загруженного списка, не обращение к стороннему боту.

Регионы определяются по загруженному справочнику `Код;От;До;Регион`. Привязка только по мобильному коду не используется: один код может принадлежать разным регионам. Определяется регион выделения номера, а не местонахождение человека.

Адреса: `г. Город, ул. Улица, д. Номер, к. Корпус, с. Строение, лит. Литера, кв. Квартира`. Сохраняются типы улиц и дополнительные сведения; неполные и неоднозначные адреса получают поле «Адрес требует проверки». Без внешнего адресного реестра нельзя гарантировать исправление любых опечаток.

ФССП ищет заголовок в первых 20 строках. Для входных XLSX/XLSM и результата XLSX сохраняются листы, формулы и оформление; макросы XLSM не переносятся в XLSX.

## Самый простой запуск локально

```bash
docker build -t dbflow .
docker run --rm -p 8080:8080 \
  -e SECRET_KEY="change-this-secret" \
  -v dbflow_data:/data \
  dbflow
```

Откройте `http://localhost:8080`.

## GitHub → Railway

1. Подключите репозиторий в Railway через **Deploy from GitHub repo**.
2. Railway автоматически использует `Dockerfile` и `railway.json`.
3. Для временных файлов нужен только Volume `/data`, который используется как рабочий каталог и очищается по TTL.
4. Регистрация, аккаунты, S3 и постоянное файловое хранилище не нужны.

## Почему CSV — основной результат

CSV не имеет ограничения Excel на число строк. По умолчанию табличные результаты — CSV; можно выбрать XLSX. Если превышен лимит листа Excel, программа предложит CSV.

## Важное про очень большие базы

Текущая версия использует Polars и обрабатывает таблицы сервером, а не браузером. Временные задачи запускаются через multipart-загрузку и очищаются после TTL.

### Временный режим

Фронтенд отправляет задачи через `POST /api/quick/jobs` как multipart-загрузку. Исходники не попадают в постоянное хранилище и не требуют регистрации. После завершения результат доступен для скачивания из истории задачи. TTL временной задачи настраивается переменной `QUICK_JOB_TTL_SECONDS`.

## Структура

```text
app/
  main.py       локальный API + временные jobs
  jobs.py       очередь/исполнение задач
  table_ops.py  быстрые операции над таблицами
  toolkit_ops.py GEO, MAX, адреса и операции Toolkit
  storage.py    временные файлы
  models.py     временные задачи и результаты
  static/       frontend desktop workspace
Dockerfile
railway.json
```

## Ограничение

Режим специально сделан временным: после TTL результаты становятся недоступны. Для постоянного хранения пользователь должен скачать их на свой компьютер.

## Проверка

Python 3.12, зависимости из requirements.txt; для API-тестов также `pip install httpx`.

```bash
python -m unittest discover -s tests -v
python -m compileall -q app tests
node --check app/static/app.js
```

Проверяются все операции, номера без запятых, совпадения/несовпадения MAX, адреса, ведущие нули, многолистовые книги, ФССП, загрузка, скачивание, изоляция сессий и очистка результатов.
